## 🧭 Overview

CostX 2026 is a meticulously engineered desktop workspace for **construction estimating**, **quantity takeoff**, and **BIM-driven cost intelligence** on Windows 11 and Windows 10. It is a digital drafting table where every beam, brick, and bolt of a project finds its price — a place where spreadsheets stop being the bottleneck and start becoming the backbone.

Rather than forcing estimators into rigid pipelines, this environment treats the building itself as a living dataset. Drawings, model elements, assemblies, and rate libraries all breathe inside the same interface, so that the moment a wall thickness changes, the cost narrative updates with it. Think of it as a translator fluent in both the language of architects and the ledger of accountants.

The repository you are reading houses the public distribution notes, setup walkthrough, feature matrix, and the roadmap for the 2026 release line. Everything here has been written with day-one usability in mind: a first-time user should be able to move from install to a working estimate in one sitting, while a seasoned quantity surveyor should discover new depths of control on every return visit.

## 🎯 Why This Project Exists

Construction estimation software has historically lived in two uncomfortable extremes. On one side, generic spreadsheet tools offer flexibility but collapse under the weight of a real multi-discipline project. On the other side, monolithic enterprise platforms offer power but demand weeks of consulting before a single takeoff can be produced. CostX 2026 was born to occupy the middle ground: powerful where it matters, gentle where it counts.

The metaphor we keep returning to is that of a **workshop**, not a factory. A factory forces every input through the same chute. A workshop lets the carpenter, the electrician, and the plumber each find their own bench while still sharing the same toolbox. That is precisely the philosophy guiding the interface, the data model, and the export pipeline here.

## ✨ Key Features

- 📐 **2D & 3D Quantity Takeoff** — measure directly on plans, elevations, sections, or BIM models without switching applications.
- 🧮 **Live Cost Assembly Engine** — link rate schedules, labor norms, and material libraries to geometry so changes propagate instantly.
- 🧩 **BIM Element Mapping** — connect model components to cost items through a flexible classification layer that respects IFC, Revit-style families, and custom taxonomies.
- 🌍 **Multilingual Interface** — the UI and report templates can be presented in multiple languages to support cross-border teams and multi-region tenders.
- 📱 **Responsive Workspace Layout** — panels, docks, and inspectors adapt smoothly from a 13-inch field tablet to a triple-monitor estimating desk.
- 🛎️ **24/7 Customer Support Desk** — asynchronous and live channels ensure that a question at 2 a.m. before a bid deadline is never left unanswered.
- 🔁 **Reusable Cost Libraries** — build once, tender many. Assemble rate books that carry across regions, calendars, and currencies.
- 📊 **Executive Dashboards** — summarize cost variance, contingency burn, and trade-level distribution at a glance.
- 🖨️ **Professional Report Generation** — export polished PDF and spreadsheet deliverables with your branding and numbering conventions.
- 🔐 **Project Vault & Audit Trail** — every edit is attributed, timestamped, and reversible, keeping teams accountable without slowing them down.
- ⚙️ **Automation Hooks** — script repetitive measurement chores through a documented internal API surface.
- 🧠 **Smart Assembly Suggestions** — heuristic hints recommend likely assemblies based on adjacent elements and historical projects.

Each of these features has been shaped by a simple question: *does this reduce the distance between a raw drawing and a confident number?* If the answer was ambiguous, the feature was redesigned until it was not.

## 🖥️ Platform & System Requirements

CostX 2026 targets the modern Windows ecosystem. It has been tuned for both the consumer-grade hardware found in a site office and the workstation-class machines used in a central estimating department.

| Component | Recommended | Minimum |
|-----------|-------------|---------|
| Operating System | Windows 11 (23H2 or newer) | Windows 10 (21H2 or newer) |
| Processor | 6-core x64, 3.0 GHz+ | 4-core x64, 2.0 GHz |
| Memory | 16 GB RAM | 8 GB RAM |
| GPU | Dedicated, 4 GB VRAM, DirectX 12 | Integrated, DirectX 11 |
| Storage | 40 GB available on SSD | 20 GB available |
| Display | 1920×1080 or higher | 1366×768 |
| Network | Broadband for library sync | Intermittent is acceptable |

A note on **BIM performance**: large federated models benefit dramatically from additional RAM and a dedicated GPU. If your daily work involves multi-discipline coordination, prioritize memory before raw clock speed — the estimating engine is more often waiting on data than on cycles.

## 🚀 Getting Started

The setup journey has been deliberately broken into small, confidence-building steps. No prior scripting knowledge is required, and no obscure dependencies need to be satisfied.

1. **Prepare the environment** — confirm your Windows build, close any heavy background applications, and make sure at least 20 GB of disk space is available.
2. **Acquire the distribution package** — obtain the official 2026 release through the distribution block below.
3. **Unpack the package** — extract the contents into a folder you can easily find later, such as a dedicated "Estimating Tools" directory.
4. **Launch the installer** — run the primary executable and accept the default component selection unless you have a specific reason to customize.
5. **Complete first-run configuration** — choose interface language, default currency, and the location of your personal cost library.
6. **Import a sample project** — use the bundled demonstration dataset to confirm that takeoff, assembly, and reporting all behave as expected.
7. **Connect your own drawings** — once the sample feels familiar, point the workspace at your real project files and begin measuring.

If any step raises a question, the support channels mentioned in the Support section operate around the clock, and the in-app help index mirrors this README almost verbatim.

## 🧪 Feature Walkthrough

### 📐 Drawing-Centric Takeoff
Open a floor plan and the measuring palette appears beside it, unobtrusive until needed. You can trace walls, count fixtures, calculate volumes, and attach a cost code to each action without ever leaving the drawing surface. The engine remembers your last-used tools, so a rhythm develops quickly: trace, tag, move on.

### 🧮 Assembly & Rate Linking
An assembly is a small recipe — a quantity of material, a slice of labor, a whisper of overhead. CostX 2026 lets you compose these recipes visually, then bind them to geometry with a single click. When the designer changes a specification, the recipe re-prices itself and the tender story stays coherent.

### 🧩 BIM Interoperability
Load a model and the workspace presents a navigable tree of elements. You can filter by level, by discipline, by material, or by any property your team has standardized on. Takeoff from a model and from a drawing can live side by side in the same estimate, which is invaluable during the transition period many firms still occupy.

### 🌍 Multilingual & Multi-Region
Currency, unit systems, and language are per-project settings rather than global ones. One estimator can work in metric with a regional language, while a colleague on the same tender works in imperial with a different one. Reports reconcile both views without manual conversion gymnastics.

### 📊 Reporting Studio
The reporting surface is closer to a small publishing tool than a print dialog. You can arrange sections, apply a house style, insert your own cover page, and preview the result exactly as it will leave the building. Templates are shareable, versionable, and diffable.

### 🔐 Accountability Layer
Every meaningful action writes to a project journal. You can answer questions like "who changed this rate last Thursday?" without interrogating three colleagues. The journal is portable, so handovers between firms during a joint venture remain transparent.

## 🧰 Extensibility & Automation

Teams that find themselves repeating the same sequence of operations every week will appreciate the automation surface. It is intentionally conservative — a small, documented set of entry points rather than a sprawling plugin universe — because predictability matters more than novelty when deadlines are tight.

Automation possibilities include:

- Batch re-pricing of assemblies after a rate sheet update.
- Scheduled export of cost summaries to a shared reporting folder.
- Automated tagging of model elements based on naming conventions.
- Custom validation rules that run before a tender is finalized.

The goal is not to turn estimators into programmers. It is to let estimators describe their habits once and then forget about them.
